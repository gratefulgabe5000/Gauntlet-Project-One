## Your Workflow: Loom → Audacity → CapCut Online

### Phase 1: Initial Recording in Loom (All-in-One)

#### Step 1.1: Set Up Loom Account
1. Visit https://www.loom.com/signup
2. Create free account or sign in with Google/Microsoft
3. Grant browser permissions for camera and microphone
4. *Optional*: Download desktop app for better performance and reliability

#### Step 1.2: Record Demo in Loom (With Audio)
1. Launch Loom (web or desktop app)
2. Click "Start Recording"
3. Choose recording mode:
   - **Screen only** (recommended for demos)
   - Screen + Camera (if you want face overlay)
   - Camera only (not relevant for this)
4. Select which screen/window to capture
5. **Keep microphone ON** - record with live narration
6. Click "Start Recording"
7. Perform your demo following FINAL-DEMO-VIDEO-SCRIPT.md or FINAL-DEMO-CUE-CARDS.md
8. Click "Finish" when done

**Tips for Loom Recording:**
- Do a 30-second test recording first
- Speak clearly and at moderate pace
- Don't worry about perfect delivery - you'll re-record audio
- Focus on smooth screen actions and good visual pacing
- Use Loom's pause feature if you need to gather thoughts

#### Step 1.3: Basic Loom Editing (Optional)
If your recording is pretty good, use Loom's AI features:
1. **Trim** unwanted sections using timeline
2. **Remove filler words** - AI auto-detects "um", "uh", etc.
3. **Remove silence** - AI cuts long pauses
4. Review and approve AI edits

#### Step 1.4: Download Loom Video
1. Click "Share" button in Loom
2. Click "Download" icon
3. Select quality (choose highest available)
4. Save MP4 file to your project folder
5. **Filename suggestion**: `CollabCanvas-Demo-Raw-Loom-Recording.mp4`

---

### Phase 2: Record High-Quality Narration in Audacity

#### Step 2.1: Set Up Recording Environment
1. Find quiet space with minimal echo
2. Close windows, turn off fans/AC temporarily
3. Test microphone levels in Audacity
4. Use pop filter if available (or improvise with sock over mic)

#### Step 2.2: Record Narration in Audacity
1. Launch Audacity
2. Check input device is correct microphone
3. Set recording level (aim for -12dB to -6dB peak)
4. Click red Record button
5. Read from FINAL-DEMO-VIDEO-SCRIPT.md
   - Record in sections matching video segments
   - Pause between sections (you'll edit later)
   - Re-do any sections that don't sound good
6. Click Stop when finished

**Pro Tip**: Watch your Loom video on another screen while recording narration in Audacity. This helps you pace your narration to match the visuals.

#### Step 2.3: Edit Audio in Audacity
1. **Select all** (Ctrl+A)
2. **Effect** → **Normalize** → OK (balances volume)
3. **Effect** → **Noise Reduction**:
   - Select a quiet section first
   - Get Noise Profile
   - Select all again
   - Apply Noise Reduction (default settings)
4. **Delete long pauses** between sections
5. **Add fade in/out**:
   - Select first 0.5 seconds
   - Effect → Fade In
   - Select last 0.5 seconds
   - Effect → Fade Out
6. Listen to entire track, make adjustments

#### Step 2.4: Export Audio
1. **File** → **Export** → **Export Audio**
2. Format: **WAV (Microsoft) signed 16-bit PCM** (best quality)
   - Or MP3 (320 kbps) if file size matters
3. **Filename**: `CollabCanvas-Demo-Narration.wav`
4. Add metadata if desired
5. Save to project folder

---

### Phase 3: Combine Video + New Audio in CapCut Online

1. **Go to https://www.capcut.com/**
2. Sign up/in (free account)
3. Click **Start creating**

4. **Upload Assets**:
   - Upload `CollabCanvas-Demo-Raw-Loom-Recording.mp4`
   - Upload `CollabCanvas-Demo-Narration.wav`

5. **Add Video to Timeline**:
   - Drag video to timeline
   - Video and its audio track appear

6. **Replace Audio**:
   - Click on the audio portion of the video track
   - Click **Detach** or right-click → Detach audio
   - Delete the detached original audio
   - Drag your `CollabCanvas-Demo-Narration.wav` to audio track

7. **Sync and Adjust**:
   - Drag audio to sync with video
   - Trim as needed
   - Use zoom slider for precision

8. **Add AI Features (Optional)**:
   - Click **Captions** → **Auto captions**
   - Choose language and style
   - Review and edit auto-generated captions

9. **Export**:
   - Click **Export** (top right)
   - Choose 1080p resolution
   - Download MP4 file
   - **Filename**: `CollabCanvas-Demo-FINAL.mp4`

## Troubleshooting

### "Loom video quality is poor"
- Use desktop app instead of browser
- Check internet connection during recording
- Record at smaller screen resolution
- Download highest quality version

### "Audio doesn't sync with video in editor"
- Both files must have same frame rate
- Try using timecode markers
- Cut video into sections and sync each part
- Re-export from Loom at different settings

### "CapCut isn't working properly"
- Check if browser needs updating (use latest Chrome/Edge)
- Try incognito/private mode
- Clear browser cache and cookies
- Disable browser extensions that might interfere
- Check internet connection speed for uploads
- Try the desktop app version instead of web

### "Audacity narration has background noise"
- Re-record in quieter space
- Use Noise Reduction effect more aggressively
- Use Gate effect to cut quiet parts
- Consider using USB microphone instead of built-in

### "Exported video file is huge"
- Use H.264 codec (not uncompressed)
- Reduce bitrate (8-10 Mbps is fine for 1080p)
- Check resolution isn't higher than needed
- Use MP4 container format

## Notes & Tips

- **Prioritize audio quality** - viewers forgive bad video but not bad audio
- **Practice your script** before recording to sound natural
- **Keep it simple** - don't over-edit or add too many effects
- **Watch your video multiple times** before submitting
- **Get feedback** from someone else if possible
- **Start early** - rendering can take longer than expected
- **Save often** - auto-save in editors isn't always reliable
- **Keep raw files** - you might need to re-edit later

### Time-Saving Tips
- Don't aim for perfection in Loom recording - you're re-doing audio anyway
- Record narration in small chunks that match video sections
- Use keyboard shortcuts in your editor (learn basic ones)
- Pre-write your script word-for-word (already done!)
- Do a 1-minute test run of entire workflow before full production
