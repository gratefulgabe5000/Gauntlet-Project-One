## 🔍 **What This Will Tell Us**

### **Scenario A: Presence Fix Is Broken**
**Console Pattern:**
```
💓 Heartbeat #1 for user abc123
🔄 Presence changed: {...}  ← BAD! Should NOT appear
🏠 App render #15
🎨 Canvas render #15
```

**What It Means:**
- Presence fix regressed during hot reload
- Every heartbeat (5 seconds) causes re-renders
- This explains the FPS drop

**Fix**: Revert presence code or fix hot reload issue

---

### **Scenario B: Presence Fix Is Working, Debounce Is Problem**
**Console Pattern:**
```
💓 Heartbeat #1 for user abc123
✅ Presence callback fired, but no change (prevented re-render)  ← GOOD!
(No App/Canvas renders)

--- But during multi-select: ---
🏠 App render #50 (many renders)
🎨 Canvas render #50 (many renders)
```

**What It Means:**
- Presence is fine
- Debounce implementation is causing the regression
- Need to fix debounce with `useMemo` instead of `useRef`

**Fix**: Proceed with Option B (fix debounce implementation)

---

### **Scenario C: Something Else**
**Console Pattern:**
```
🏠 App render #100
🏠 App render #101
🏠 App render #102
(Constantly incrementing, no heartbeat correlation)
```

**What It Means:**
- Different source of re-renders
- Possibly `activeUsers` prop changes
- Or another state update loop

**Fix**: Deep dive with React DevTools Profiler
