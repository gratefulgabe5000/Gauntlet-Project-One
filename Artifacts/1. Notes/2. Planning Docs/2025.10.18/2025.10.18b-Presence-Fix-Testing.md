## ✨ **The Fix Explained**

### **Before (Buggy):**
```typescript
// Closure captured stale value of currentUserColor
const unsubscribe = subscribeToPresence((users) => {
  if (currentUser.cursorColor !== currentUserColor) {  // ❌ Always fails!
    setCurrentUserColor(currentUser.cursorColor);
  }
});
```

Every 5 seconds (heartbeat), this check would fail because `currentUserColor` was stale, triggering `setState` → App re-render → performance hit.

### **After (Fixed):**
```typescript
// Refs provide fresh values without triggering dependency changes
const currentUserColorRef = useRef<string>(currentUserColor);

const unsubscribe = subscribeToPresence((users) => {
  if (currentUser.cursorColor !== currentUserColorRef.current) {  // ✅ Fresh value!
    setCurrentUserColor(currentUser.cursorColor);
    currentUserColorRef.current = currentUser.cursorColor;  // Update ref
  }
});
```

Now `setState` only fires when the value **actually changes**, not on every heartbeat! 🎉
