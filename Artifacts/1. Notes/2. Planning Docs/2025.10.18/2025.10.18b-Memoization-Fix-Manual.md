## 🎯 **Why This Works**

### **Before (Current)**:
- Every time `selectedShapeIds` changes, Canvas re-renders
- On each render, new callback functions are created for EVERY shape
- React.memo() sees new props (even though data is the same) → re-renders ALL shapes
- **Result**: 13 FPS with 20 shapes selected

### **After (With useMemo)**:
- `useMemo` only re-creates shape elements when dependencies change
- If only `selectedShapeIds` changes, shapes with unchanged selection state keep same props
- React.memo() sees same props → skips re-render for unchanged shapes
- **Result**: Only re-render shapes whose selection state changed → 60 FPS
