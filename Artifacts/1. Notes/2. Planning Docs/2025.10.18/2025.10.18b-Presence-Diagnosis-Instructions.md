## 🎯 **Objective**

Identify what's causing excessive re-renders and FPS regression. We've added diagnostic logging to:
1. **usePresence.ts** - Track presence callbacks and updates
2. **App.tsx** - Track App component renders
3. **Canvas.tsx** - Track Canvas component renders

---

## 📋 **Test Procedure**

### **Test 1: Idle Monitoring (Baseline)**

**Goal**: See if presence heartbeat is causing re-renders when nothing is happening

1. **Refresh the page** (to get a clean start)
2. **Wait 10 seconds** (do nothing, just let it idle)
3. **Open browser console** and look for patterns

**What to Look For:**
```
✅ Presence callback fired, but no change (prevented re-render)  ← GOOD
💓 Heartbeat #1 for user [id]  ← Expected every 5 seconds
🏠 App render #X  ← Should NOT increase constantly
🎨 Canvas render #X  ← Should NOT increase constantly
```

**Expected Behavior:**
- Heartbeat logs every 5 seconds: ✅ Normal
- "Presence callback fired, but no change": ✅ Good (our fix is working)
- App/Canvas re-renders: ❌ BAD (indicates problem)

---

### **Test 2: Create AI Shapes (Load Test)**

**Goal**: See if AI commands trigger excessive re-renders

1. **Clear console** (Ctrl+L or Cmd+K)
2. **Open AI panel** (Cmd/Ctrl+K)
3. **Type**: "Create 20 circles"
4. **Watch console** during creation
5. **Wait 5 seconds** after creation completes

**What to Look For:**
```
🔄 Canvas update received: 1 shapes  ← Expected 20 times
🏠 App render #X  ← Count how many
🎨 Canvas render #X  ← Count how many
✅ Presence callback fired, but no change  ← Should appear
🔄 Presence changed:  ← Should NOT appear (unless user joins)
```

**Questions to Answer:**
- How many App renders during creation? (Note the number)
- How many Canvas renders during creation? (Note the number)
- Does "Presence changed" appear? (Should be NO)
- Does "Presence callback fired, but no change" appear? (Should be YES)

---

### **Test 3: Multi-Select (The Problem Case)**

**Goal**: Identify what's triggering re-renders during multi-select

1. **Clear console**
2. **Click on one circle** (select it)
3. **Hold Shift**
4. **Click 5 more circles** (multi-select)
5. **Watch console** closely

**What to Look For:**
```
🏠 App render #X  ← How many times?
🎨 Canvas render #X  ← How many times?
✅ Presence callback fired, but no change  ← Appearing?
🔄 Presence changed:  ← Should NOT appear
```

**Critical Questions:**
- How many renders for 6 selections? (Should be ~6-12, not 50+)
- Is presence callback firing during selection? (Shouldn't be)
- Is there a pattern to the timestamps?

---

### **Test 4: Presence Heartbeat Deep Dive**

**Goal**: Verify the heartbeat is NOT causing re-renders

1. **Clear console**
2. **Wait for a heartbeat** (look for `💓 Heartbeat #X`)
3. **Note the timestamp**
4. **Look at logs 1-2 seconds AFTER the heartbeat**

**What to Look For:**
```
💓 Heartbeat #2 for user [id]  ← Heartbeat fires
✅ Presence callback fired, but no change  ← Should appear right after
🏠 App render #X  ← Should NOT appear
🎨 Canvas render #X  ← Should NOT appear
```

**Expected Sequence:**
1. Heartbeat logs: `💓 Heartbeat #2`
2. Presence callback: `✅ Presence callback fired, but no change`
3. NO App/Canvas renders

**If App/Canvas renders after heartbeat:** 🚨 **PRESENCE BUG FOUND!**

---

### **Test 5: Hot Reload Impact**

**Goal**: See if hot reload is breaking things

1. **Clear console**
2. **Note current render counts** (App #X, Canvas #Y)
3. **Make a small change** to any file (add a comment)
4. **Save** (trigger hot reload)
5. **Watch console** during reload
6. **Wait 10 seconds** after reload

**What to Look For:**
```
[vite] hot updated: /src/App.tsx  ← Hot reload happening
🏠 App render #1  ← Should reset to #1
🎨 Canvas render #1  ← Should reset to #1
💓 Starting presence heartbeat  ← Heartbeat restarts
```

**After Hot Reload:**
- Do renders constantly increment? ❌ BAD
- Does it stabilize after initial load? ✅ GOOD
- Any React errors in console? 🚨 CRITICAL
