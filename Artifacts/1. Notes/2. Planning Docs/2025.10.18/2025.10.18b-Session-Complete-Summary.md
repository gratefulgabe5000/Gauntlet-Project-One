## 🎓 **Key Learnings**

### **1. useRef vs useMemo**
**Rule**: For memoized functions with closures, **ALWAYS use useMemo**, NOT useRef!

| Use Case | Tool | Reason |
|----------|------|--------|
| Mutable ref (DOM) | `useRef` | Stable reference, manual updates |
| Memoized function | `useMemo` | Fresh closures, React-compliant |
| Memoized value | `useMemo` | Recomputes on dep changes |

### **2. Empty Deps + Params Pattern**
```typescript
const memoizedFn = useMemo(
  () => createFunction((params) => {
    // Pass values via params, not closures
    params.callback(freshValue);
  }),
  [] // Empty deps - stable function
);
```
**Benefits**: Stable function + fresh values + no stale closures
