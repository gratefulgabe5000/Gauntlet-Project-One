## 🎯 **What We're Looking For**

### **Smoking Gun #1: Shapes Reference Changes on Selection**
```
🏠 App render #N { shapesCount: 20, selectedCount: 1 }
⚠️ Shapes reference CHANGED  ← 🚨 **THIS IS THE BUG!**
```

**Diagnosis**: If shapes reference changes when selecting, it means:
- useShapes hook is creating a new array unnecessarily
- Even though shape data hasn't changed, the array reference changes
- This forces useMemo to re-run → all shapes recreate → React.memo() fails

**Fix**: Memoize the shapes array in useShapes hook

---

### **Smoking Gun #2: Excessive App Renders**
```
🏠 App render #N   { shapesCount: 20, selectedCount: 1 }
🏠 App render #N+1 { shapesCount: 20, selectedCount: 1 }  ← Same state!
🏠 App render #N+2 { shapesCount: 20, selectedCount: 1 }  ← Why 3 times?
```

**Diagnosis**: If App renders multiple times with same state:
- Multiple state updates not being batched
- Some useEffect or state setter causing cascading updates

**Fix**: Batch updates or consolidate state changes

---

### **Smoking Gun #3: useMemo Re-runs Every Time**
```
🏠 App render #N
🔨 useMemo re-ran - creating 20 shape elements  ← Every time!
```

**Diagnosis**: If useMemo re-runs on every selection:
- One of its dependencies is changing
- Either shapes, selectedShapeIds, or a callback

**Fix**: Stabilize whichever dependency is changing

## 🔬 **Next Steps Based on Findings**

### **If "Shapes reference CHANGED" appears on selection**:

### **If App renders 3+ times per selection**:
