### **IMMEDIATE PRIORITY: Phase 4a Block 3 (30 minutes)**

**Goal**: Complete final Phase 4a block for full 10/10 points

**Tasks**:

#### 1. Code Refactoring (15 minutes)
- **Extract Transform Utilities**: Consolidate duplicate resize/rotation logic
  - All 5 shape components share similar transform patterns
  - Create shared utility functions in `src/utils/transform.ts`
  - DRY principle: Remove duplicated code
  
- **Shape Component Cleanup**: Review all 5 shape components
  - Rectangle.tsx, Circle.tsx, Text.tsx, Line.tsx, Arrow.tsx
  - Extract common patterns (localBounds, resizeState, rotation logic)
  - Improve code modularity and readability

#### 2. Comprehensive Error Handling (10 minutes)
- **Firestore Operations**: Wrap all async calls in try/catch
  - `src/services/firestore.ts` - All CRUD operations
  - User-friendly error messages with toast notifications
  
- **AI Command Execution**: Enhance error handling
  - `src/hooks/useAICommands.ts` - Command parsing failures
  - `src/services/openai.ts` - API rate limits, network errors
  - Graceful degradation (offline mode, fallback behavior)

- **Shape Operations**: Validate inputs
  - Minimum size constraints (prevent negative dimensions)
  - Boundary checks (shapes stay within canvas)
  - Color validation (valid hex/color names)

#### 3. Security Audit (5 minutes)
- **Environment Variables**: Verify no exposed secrets
  - Check `.env.local` is in `.gitignore`
  - Confirm `VITE_OPENAI_API_KEY` not committed to repo
  - Review Firebase config (public keys are safe)

- **Firestore Security Rules**: Review and document
  - Users can only modify their own shapes
  - Read access for all authenticated users
  - Rate limiting considerations

- **AI Command Rate Limiting**: Add client-side throttle
  - Prevent spam (max 1 command per 2 seconds)
  - Simple implementation: track last command timestamp
  - Display "Please wait..." message if throttled

**Success Criteria**:
- ✅ No duplicate code across shape components
- ✅ All async operations have error handling
- ✅ No exposed API keys in codebase
