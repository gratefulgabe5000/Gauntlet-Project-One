## 📊 **What You'll See in LangSmith**

Once configured, each AI command will show:
- **Input**: User's natural language command
- **System Prompt**: Full context sent to AI
- **Tools Called**: Which canvas tools were invoked
- **Tool Arguments**: Exact parameters passed
- **Token Usage**: Prompt tokens, completion tokens, cost
- **Duration**: Response time in milliseconds
- **Success/Error**: Command outcome
