## 🎯 **Objective**

Reduce Firestore write frequency during shape dragging operations to improve sync latency and reduce database load.

---

## ⚠️ **The Problem**

### **Before Debouncing:**
- Every drag operation triggered an immediate Firestore write
- Sync latency: **688ms average** (CRITICAL)
- Rapid drags (e.g., user drags a shape multiple times quickly) created multiple Firestore writes
- Each write took ~688ms, making the app feel sluggish

### **Impact:**
- Poor perceived performance
- Unnecessary Firestore writes
- Higher database costs
- Slower undo/redo operations

---

## ✅ **The Solution: Debounced Firestore Writes**

### **How It Works:**

1. **Optimistic UI Updates (Immediate)**
   - Local state updates happen instantly
   - User sees smooth, responsive dragging
   - No delay in visual feedback

2. **Debounced Firestore Writes (200ms delay)**
   - Firestore writes are delayed by 200ms
   - If another position update occurs within 200ms, the previous write is cancelled
   - Only the final position is written to Firestore
   - Undo/redo action is only recorded after successful Firestore write

### **Example Scenario:**

**User drags a shape 3 times in quick succession:**

| Time | Event | Local State | Firestore Write |
|------|-------|-------------|-----------------|
| T+0ms | Drag #1 | ✅ Update | ⏳ Schedule (200ms) |
| T+100ms | Drag #2 | ✅ Update | ❌ Cancel #1, ⏳ Schedule new (200ms) |
| T+150ms | Drag #3 | ✅ Update | ❌ Cancel #2, ⏳ Schedule new (200ms) |
| T+350ms | (Wait) | - | ✅ Write #3 to Firestore |

**Result:** 3 drags = 1 Firestore write instead of 3!

## 📝 **Implementation Details**

### **1. Debounce Utility**

Added to `src/utils/performance.ts`:

```typescript
export function debounce<T extends (...args: any[]) => any>(
  func: T,
  wait: number
): (...args: Parameters<T>) => void {
  let timeoutId: NodeJS.Timeout | null = null;
  
  return function(this: any, ...args: Parameters<T>) {
    const context = this;
    
    if (timeoutId) {
      clearTimeout(timeoutId);
    }
    
    timeoutId = setTimeout(() => {
      func.apply(context, args);
      timeoutId = null;
    }, wait);
  };
}
```
