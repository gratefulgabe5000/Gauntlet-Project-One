## 🎯 **Problem**

After implementing `useMemo` in Canvas.tsx, multi-select performance improved from 13 FPS → 24 FPS, but didn't reach our 60 FPS target.

### **Root Cause**

The `useMemo` dependency array in Canvas.tsx included callback functions that were being recreated on every App.tsx render:

```typescript
useMemo(() => {
  // ... shape rendering ...
}, [
  shapes,
  selectedShapeIds,
  onSelectShape,           // ← Recreated on every App.tsx render
  onShapeDragStart,        // ← Breaking memoization
  onDuplicateShape,        // ← Causing all shapes to re-render
  onShapeDragEnd,
  onUpdateShapePosition,
  onUpdateShapePositionAndDimensions,
  onUpdateShapeDimensions,
  onUpdateShapeProperties,
  onTextChange,            // ← Recreated on every App.tsx render
]);
```

Every time App.tsx re-rendered, these callback functions got new references → `useMemo` saw "changed" dependencies → recreated all shape elements → React.memo() didn't prevent re-renders → 24 FPS instead of 60 FPS.

---

## 🔧 **Solution: Stabilize Callbacks with useCallback**

Wrapped all local handler functions in App.tsx with `useCallback` to ensure stable references across renders.

## 🎯 **How This Works**

### **Before (24 FPS)**
1. User selects a shape
2. App.tsx re-renders (state change)
3. All handler functions recreated with new references
4. Canvas.tsx receives "new" props
5. `useMemo` sees changed dependencies
6. All shape elements recreated
7. React.memo() can't prevent re-renders (props changed)
8. **All 20 shapes re-render** → 24 FPS

### **After (Expected 60 FPS)**
1. User selects a shape
2. App.tsx re-renders (state change)
3. Handler functions keep same references (useCallback)
4. Canvas.tsx receives same callback props
5. `useMemo` dependencies unchanged (except `selectedShapeIds`)
6. Only shapes with changed selection state recreated
7. React.memo() prevents re-renders for unchanged shapes
8. **Only 2 shapes re-render** (selected + deselected) → 60 FPS! 🎉

## 🎓 **Key Learnings**

### **1. Memoization Requires Stable Props**
- React.memo() only works if props are referentially stable
- useMemo only works if dependencies are referentially stable
- Both must work together for optimal performance

### **2. Callback Stability Chain**
```
App.tsx useCallback → Canvas.tsx useMemo → Shape React.memo()
     ↓                      ↓                     ↓
Stable props          Stable elements      Prevent re-renders
```

All three must be stable for the optimization to work!

### **3. Hook Callbacks Should Be Memoized**
Custom hooks should return memoized callbacks to prevent breaking consumer components' memoization.

### **4. Empty Dependency Arrays for Pure Functions**
Functions that only access props/params (no closure over state) can use `[]` as dependencies.
