## 🐛 **Bug #1: Dropped Frames Incorrectly Showing 59-60**

### **Problem**
- Performance Stats showed "Dropped: 59-60" even with perfect 60 FPS
- Made it look like performance was terrible when it was actually excellent

### **Root Cause**
The FPSMonitor was using the same `lastTime` variable for two different purposes:
1. Calculating time since last frame (frame delta)
2. Calculating time since last FPS update (1 second intervals)

This meant every frame was being measured against the last FPS update time (~1000ms), not the last frame time (~16ms), causing ALL frames to be counted as "dropped".

### **Fix**
```typescript
// BEFORE: Single timer (broken)
private lastTime: number = performance.now();

// AFTER: Separate timers (fixed)
private lastFrameTime: number = performance.now();
private lastFpsUpdateTime: number = performance.now();
```

**Result**: Dropped frames now correctly counts only frames that take >16.67ms to render.

## 🐛 **Bug #2: Sync Latency Section Not Appearing**

### **Problem**
- User reported: "The model needs 'Sync Latency' if I'm to monitor it under load"
- Sync Latency section was not showing up in Performance Stats
- This was because no sync operations were being monitored

### **Root Cause**
We created the `globalSyncMonitor` utility, but never actually integrated it into the Firestore operations. The condition `syncMetrics && syncMetrics.sampleCount > 0` was always false because no data was being tracked.

### **Fix**
Added sync monitoring to key Firestore operations in `useShapes.ts`:

```typescript
// Track addShape (create operations)
const syncId = `create-${Date.now()}`;
globalSyncMonitor.startSync(syncId);
const result = await createShape(shapeData, user.uid);
globalSyncMonitor.endSync(syncId);

// Track updateShapePosition (most frequent - drag operations)
const syncId = `update-pos-${shapeId}-${Date.now()}`;
globalSyncMonitor.startSync(syncId);
const result = await updateShape(shapeId, { x, y }, user.uid);
globalSyncMonitor.endSync(syncId);

// Track updateShapeColor (bulk operations)
const syncId = `update-color-${shapeId}-${Date.now()}`;
globalSyncMonitor.startSync(syncId);
const result = await updateShape(shapeId, { fill: color }, user.uid);
globalSyncMonitor.endSync(syncId);
```

**Result**: Sync Latency section now appears and shows real-time Firestore sync performance!
